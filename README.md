# JogoDomino-Java
Jogo de Domino feito em Java utilizando JAVAFX para a aula de Laboratório de Estruturas Dinâmicas
## Funcionalidades
- Jogar um jogo de dominó clássico VS a máquina
- Salvar o jogo
- Carregar o jogo
## Tecnologias Utilizadas
- Java
- JavaFX
- CSS
## Instalação e Execução
1. Fazer Download dos arquivos disponibilizados
2. Certificar-se de que seu IDE ou Editor tem como rodar aplicações JavaFX
3. Rodar pelo arquivo DominoFXApp.java
